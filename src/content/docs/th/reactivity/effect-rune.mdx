## effect sync กับโลกภายนอก

`$effect` รัน function หลัง DOM update แล้ว และรันซ้ำทุกครั้งที่ค่า reactive ที่มันอ่านเปลี่ยน มันมีไว้สำหรับ **side effect** — sync state ของ Svelte กับสิ่งที่อยู่นอก Svelte: DOM ตรง ๆ, library ภายนอก, subscription, timer, logging, `localStorage`

```svelte
<script>
  let count = $state(0);

  $effect(() => {
    // Runs after render, and again whenever count changes.
    document.title = `Count: ${count}`;
  });
</script>
```

dependency ถูก track อัตโนมัติ เหมือน `$derived` เป๊ะ — effect อ่าน `count` มันจึงรันซ้ำเมื่อ `count` เปลี่ยน ไม่ต้องมี dependency array

## Cleanup

ถ้า effect ตั้งอะไรบางอย่างที่ต้อง tear down — interval, event listener, subscription — ให้ **return cleanup function** Svelte จะรันมันก่อน effect รันซ้ำ และตอน component ถูก destroy

```svelte
<script>
  let seconds = $state(0);

  $effect(() => {
    const id = setInterval(() => seconds++, 1000);
    return () => clearInterval(id);   // cleanup: runs before re-run and on destroy
  });
</script>
```

## $effect.pre

`$effect` รัน **หลัง** DOM update บางครั้งคุณต้องอ่าน DOM *ก่อน* มัน update — เช่น จับ scroll position ก่อน content ใหม่จะดันมันไป **`$effect.pre`** รันก่อน DOM update แทน โดยมีกฎ track และ cleanup เหมือนกัน

```svelte
<script>
  let messages = $state([]);

  $effect.pre(() => {
    messages.length;                 // track the dependency
    // read scroll position BEFORE the DOM updates with new messages
  });
</script>
```

## ส่วนใหญ่คุณไม่ต้องใช้ effect

นี่คือแนวทางที่สำคัญที่สุดในโมดูล effect คือ escape hatch และการหยิบมันมาจัดการ state *ภายใน* คือความผิดพลาดที่พบบ่อยที่สุดใน Svelte 5 ก่อนเขียน effect ให้ถามว่า:

- **คำนวณค่าจาก state?** ใช้ `$derived` ไม่ใช่ effect ที่ assign state
- **ตอบสนอง user action?** ทำงานใน event handler (`onclick`) ไม่ใช่ effect ที่คอยดูตัวแปร
- **mirror prop ลง state?** มักเป็น design smell — derive จาก prop แทน

<Callout title="สรุปบรรทัดเดียว">
`$effect(fn)` รัน **หลัง DOM update** และรันซ้ำเมื่อค่าที่ track อ่านเปลี่ยน — สำหรับ **side effect ที่เชื่อมไปโลกภายนอก** (DOM, subscription, timer, `localStorage`) ให้ return **cleanup function** เพื่อ tear down subscription/interval และใช้ **`$effect.pre`** เพื่อรันก่อน DOM update ที่สำคัญ **ส่วนใหญ่คุณไม่ต้องใช้ effect**: derive ค่าด้วย `$derived` ทำงานจาก action ใน event handler และเก็บ `$effect` ไว้สำหรับ sync กับภายนอกจริง ๆ
</Callout>
